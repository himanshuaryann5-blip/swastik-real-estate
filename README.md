# Swastik Real Estate — Website Demo

A lightweight, responsive three-page static website for preview and deployment.

## Pages
- `index.html` — Home
- `properties.html` — Properties & Services
- `contact.html` — About & Contact

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy
Upload the folder to Netlify, or import it into a GitHub repository and deploy as a static site on Netlify or Vercel. No build command is required; set the publish/output directory to the project root.

## Important demo notes
- Property cards are illustrative examples, not live or verified inventory.
- Enquiry forms validate basic fields and open WhatsApp with a pre-filled message. They do not store submissions in a database and do not claim to have sent a message.
- Images and Google Fonts are loaded from external URLs, so internet access is needed for those assets.
- The supplied Google Maps link is labeled “View Business Location”; it has not been verified against both listed addresses.
- Business details are taken from the supplied project brief. Please verify them with the client before public launch.
